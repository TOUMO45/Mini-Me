## LinkedIn

Attach: the reel, or `marketing/infographic/Mini_Me_Infographic_4x5_2x.png`. Put `[link]` in the first comment, not in the post.

```
Every AI tool has memory now. Yet most of us still correct the same mistakes, week after week.

The problem isn't that AI forgets. It's that it remembers the wrong thing.

AI memory stores facts: "the user prefers short emails." But real work runs on decisions with context:

→ Put the decision first, because this client skims.
→ Skip the case studies, but only for this proposal.
→ Use bullet points, but that's my manager's rule for leadership documents, not mine.

Get that context wrong and an assistant either forgets the lesson or applies it everywhere. Both cost you time.

So I built Mini Me, a skill that learns how you work and why:

1. Learn: one edit plus one reason becomes a reusable rule, with its evidence.
2. Scope: every rule knows where it applies. One-offs expire. A colleague's instructions stay theirs. A client's brief stays with that client.
3. Recall: for each new task, it brings back only the rules that matter and flags the ones that were replaced or expired. On a 61-record test profile, that's about 570 tokens of context instead of 6,100.

Trust was a design requirement, not a feature. Your memory is a plain file you own. You can see every rule, correct it or delete it. Every inference is labelled as confirmed, likely or tentative. It refuses to store passwords or keys.

I built it test-first: each behaviour was graded against criteria written before any test ran. The tests are synthetic so far, so the next step is real-world proof.

I'm looking for 5 professionals who use Claude Code, Cursor or another MCP agent daily to pilot it for two weeks. We'll measure one thing: how many edits it takes you to accept the AI's work.

Interested? Comment "pilot" or send me a message.

#AI #AIAgents #Productivity #FutureOfWork
```

## Posting notes

- **Native media wins.** Upload the reel file directly. Don't link to it.
- **X:** one or two hashtags. More looks spammy and doesn't add reach. Post the thread from 1/, then pin it.
- **LinkedIn:** the first two lines show before "…see more", so the hook is written for them. Links in the post body are widely reported to reduce reach, so the link goes in the first comment.
- **Reply fast.** Answering comments in the first hour keeps the post circulating on both platforms.
- **Turn replies into proof.** If pilot users report results, those numbers make the strongest follow-up post. Only post numbers you've measured.
